# Agentes - Instruções

## Regras de Commit

**Toda alteração feita neste repositório DEVE ser commitada e enviada (push) ao GitHub.**

Após qualquer modificação em arquivos do projeto, execute:

```bash
git add -A
git commit -m "descreva brevemente a alteração"
git push
```

Isso se aplica a todas as alterações: criação, edição, exclusão de arquivos, correções de bugs, refatoração, etc.

## Fluxo de Trabalho

1. Sempre que uma tarefa for concluída, faça commit e push imediatamente
2. Nunca deixe alterações pendentes sem commit
3. Mensagens de commit devem ser claras e concisas em português ou inglês
